# Embedded Systems Portfolio

This repository showcases a curated set of embedded systems labs completed on the TI MSPM0 LaunchPad platform. The work highlights practical experience with firmware development, real-time control, peripheral interfacing, and hardware debugging in a microcontroller environment.

## What this portfolio demonstrates
- Embedded C and low-level firmware development
- GPIO and board-level hardware control
- UART and serial communication
- Analog-to-digital conversion and sensor interfacing
- Timer interrupts and periodic task scheduling
- LCD display integration and user-facing output
- Debugging, validation, and iterative hardware development

## Core lab set included
- Lab 1: Assembly and controller logic fundamentals
- Lab 2: Microcontroller programming and system behavior
- Lab 3: Data handling and debugging workflows
- Lab 4: Finite-state logic and control systems
- Lab 5: DAC waveform generation and audio-related signal output
- Lab 6: UART, string conversion, and timing-sensitive I/O routines
- Lab 7: Sensor input, calibration, and embedded measurement tasks
- Lab 8: UART communication, interrupt-driven timing, and sensor-distance measurement

## Toolchain and platform
- TI MSPM0G3507 microcontroller
- TI Code Composer Studio / clang-based embedded workflow
- Peripheral-driven firmware development using MSPM0 hardware features

## Project scope
This collection focuses on the core, completed labs that best reflect embedded-systems skills: firmware design, low-level debugging, communication, timing, and hardware integration. It intentionally excludes H-version labs, example projects, and generated build artifacts that are not relevant to a portfolio narrative.
